First consultation

What to expect

The first consultation is long. It includes conversation, examination and a clear explanation of the options, including the option not to intervene. Bring recent test results, if you have them, and a list of the medication you take.

Appointments have a set time and an interval between them, so nobody waits in a crowded room. If you need to reschedule, let us know by WhatsApp.
